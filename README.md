# Бесплатная автообновляемая VPN-подписка v0.3

Эта версия переделана под полностью бесплатную схему на GitHub Actions.

## Как работает

Каждые 5 минут GitHub сам запускает временный Linux-компьютер:

1. скачивает три источника `igareck/vpn-configs-for-russia`;
2. объединяет ключи;
3. удаляет дубли;
4. поднимает каждый VPN через Xray или sing-box;
5. делает реальный HTTP-запрос через конкретный VPN;
6. успешный тест сбрасывает счётчик ошибок в 0;
7. неудачный тест добавляет +1;
8. после 5 неудачных запусков подряд ключ удаляется;
9. обновлённая подписка сохраняется в `output/subscription.txt`.

Никакого постоянного blacklist нет. Если удалённый ключ снова появляется в исходных
GitHub-файлах, он снова попадает в кандидаты.

## Деньги

- VPS: не нужен.
- Домашний компьютер 24/7: не нужен.
- Публичный GitHub repository + standard GitHub-hosted Actions: используем бесплатную схему.

## Почему проверка сервера раз в 5 минут, а не каждые 30 секунд

Постоянного сервера у нас нет. GitHub Actions запускает отдельные короткие задания.
Финальный быстрый выбор и failover должен происходить уже на устройстве через клиент
с `url-test` / `fallback`.

То есть:
- GitHub очищает общий пул;
- VPN-клиент на телефоне/TV/ПК выбирает лучший из этого пула локально.

## Что нужно сделать

1. Создать новый PUBLIC repository в GitHub.
2. Распаковать содержимое этого архива в корень repository.
3. Commit + Push.
4. Открыть вкладку Actions и разрешить workflows, если GitHub попросит.
5. Запустить `Refresh VPN subscription` вручную первый раз.
6. После успешного запуска постоянная простая подписка будет доступна по RAW-ссылке:
   `https://raw.githubusercontent.com/USER/REPO/main/output/subscription.txt`

## Важно

`subscription.txt` — универсальный список share-links.

Следующий этап после первого успешного запуска:
- сформировать Mihomo/Clash конфиг с AUTO + fallback;
- сформировать sing-box конфиг с urltest;
- подобрать конкретные бесплатные клиенты под Android/TV/Windows 7.

Именно локальный AUTO/failover решит проблему того, что между двумя серверными
проверками отдельный бесплатный VPN может умереть.
